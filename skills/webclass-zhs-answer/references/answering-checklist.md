# 作答检查单

> 每次开答前、交卷前各过一遍。逐项打勾，缺项不开始、不提交。

## A. 开工前

- [ ] 浏览器桥可用：`browser_snapshot` 能读到页面标题与 URL。
- [ ] 页面是 `studentReviewTestOrExam`（H5 复习考试页），不是 `examPreview` 预览页、视频课或目录。
- [ ] 已记录起始 `paperId`、`classId`、`pointId`（从 URL query 里抄）。
- [ ] 已拿到答案表（题号 → 选项字母），且用户确认过答案归属。
- [ ] **必学资源全绿**：底部「必学资源」每张卡都有 `.finished-icon`（`cards === done`）。
- [ ] 有未完成卡时已补看：点卡 → 拖进度条到 `duration - 5s` → 等 `video.ended` → 刷新复查。
- [ ] 复查仍缺 → 已 `wait_human` 并报小节名，未在资源未完成的点上开卷。
- [ ] 用户名下没有别的未提交尝试 —— 有就先问「旧卷要不要先处理」。

## B. 逐题点选

- [ ] 题型确认：单选点 `li`（圆点），多选点 `label`（复选框）；点错元素不生效。
- [ ] 选项文本与答案表逐字一致（尤其多选，四个选项都要核对）。
- [ ] 每点一项后 `browser_screenshot` 复核：单选看蓝点、多选看蓝勾。
- [ ] 多选从 A→B→C→D 顺序点，每点一项截一次图。
- [ ] 不点「错题反馈」「重新答题」「AI答题辅导」「收藏为薄弱题」。

## C. 切题保存

- [ ] 每题选完点「下一题」，`browser_wait 800ms` 后再快照。
- [ ] 答题进度 +25%（0 → 25 → 50 → 75 → 100%），新题已渲染。
- [ ] 末题「下一题」灰：点「上一题」触发保存，确认进度到 100%。
- [ ] 末题保存后再点「下一题」回看，选项仍在。

## D. 提交（仅限用户明确授权）

- [ ] 用户原话里出现「提交」或等价指令。
- [ ] 全卷复核完成：答题卡 1–4 逐题截图，与答案表一致。
- [ ] 点「提交作业」后立刻截图：跳到知识点分析页，看「已答对 n / 总题数」。
- [ ] 若未跳转 / 空白：重试一次快照，仍异常则截图报用户。
- [ ] **掌握度 ≥ 90** 才收工；< 90 已重做（最多 2 次），仍不达标已记「未达标 + 最好成绩」。

## E. 禁止清单（整场有效）

- [ ] 不用脚本写 `video.currentTime` / 伪造播放心跳（只许操作播放器自带进度条）。
- [ ] 不在必学资源未全绿时点「去提升」。

- [ ] 未授权不提交。
- [ ] 不点「错题反馈」（会进错题本/新学习流）。
- [ ] 不点「重新答题」（重置尝试记录）。
- [ ] 不点「AI答题辅导」「收藏为薄弱题」。
- [ ] 不在 `paperId` 变化（跨卷）后继续作答。
