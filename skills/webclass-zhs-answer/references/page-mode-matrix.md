# 页面模式对照表

> 智慧树 H5 同一门课会出现五种页面。动作前先对号入座；对不上说明走错页，停下换页。

| 页面 | URL 特征 | 可做 | 不可做 |
|---|---|---|---|
| 复习考试答题页 | `studentexamcomh5.zhihuishu.com/studentReviewTestOrExam/...`（query 带 `paperId` / `examPaperId` / `classId` / `pointId`） | 点选选项、翻页、照授权点「提交作业」 | 不点「错题反馈」「重新答题」「AI答题辅导」「收藏为薄弱题」 |
| 题目预览/解析页 | `ai-smart-course-student-pro.zhihuishu.com/examPreview/...` | 只读核对：每题「回答正确/回答错误」+ 参考答案 | 没有编辑入口；点「重新答题」会重置整卷 |
| 知识点分析页 | 提交后跳转：圆形掌握度百分比、「总题数 / 已答对」、「查看作答记录与解析」 | 只读留证 | — |
| 视频课 / 目录 | `videoplay`、`catalog` 类路径 | 不属于本技能 | 走 `webclass-zhs-drive` |
| 作业列表 / 课程主页 | 班级作业、进度条、待办 | 只读 | 不属于本技能 |

## 即时判题（key insight）

复习模式下，每道题**选中即判**：预览页会直接显示「回答正确/回答错误 + 参考答案」，
**错选后没有改答案入口**（本次实测：第 2 题选 BD 判错，参考答案 A、B、C、D，无法回改）。

推论：

1. 答案必须在点选前定准，别指望「先随便选、后面再改」。
2. 判错后想要正确记录，只能走平台提供的「重新答题」入口 —— 那是**用户**的决策，
   代理不要自己点。
3. 判题结果可能在提交前就已可见；看到「回答错误」先停手核对，不要继续把错答扩散到其它题。
